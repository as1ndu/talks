# Talks

Hosting & archive for slides talks I have given. Located at [https://asxndu.tngl.io/talks](https://asxndu.tngl.io/talks)

## Usage

```bash
marp ./slides/{talk-name}.md -o ./{talk-name}/index.html
```

**Colophon:**
Uses _[Markdown](https://github.com/marp-team/marp-core/blob/main/docs/markdown.md)_, _[Marp](https://github.com/marp-team/marp)_ and the _[Rose Pine](https://github.com/rainbowflesh/Rose-Pine-For-Marp)_ theme.
